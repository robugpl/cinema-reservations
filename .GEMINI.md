0. The project is built in PHP, using the Symfony framework.
1. Class constructors should be written to define as many class attributes as possible. For example:
    ```
    <?php
    class A
    {
        public function __construct(
            private readonly int $a, 
            private readonly string $b
        ){}
    }
    ```

2. Generate getters only where necessary. That is, if attributes are not needed outside the class, refrain from
   generating a getter.
3. Add setters only when necessary, that is, when they will be needed to change the state of a class instance. In
   other cases, pass data through constructors.
4. Diagrams are saved in docs directory, using Mermaid format (.mmd file extension). Namespaces are written in snake case, starting every part with capital letter. 
   Use these namespaces in PHP code by replacing _ characters with \
5. Each module is clearly separated into layers:
    - Infrastructure
    - Domain
    - Application
6. Follow SOLID, DRY and KISS principles.
